5. شروط غیرقابل مذاکره (Hard Gates)
صرف‌نظر از امتیاز نهایی، در موارد زیر تأمین‌کننده نباید فعال شود:
* هویت و اطلاعات تماس قابل اعتبارسنجی نیست.
* اصالت یا منشأ کالا مشخص نیست.
* مدارک قانونی لازم برای گروه محصول ارائه نشده‌اند.
* نمونه کالا با مشخصات اعلامی تطابق ندارد.
* شرایط مسئولیت خرابی، مغایرت و مرجوعی روشن نیست.
* تأمین‌کننده اطلاعات موجودی یا زمان تحویل را به‌صورت گمراه‌کننده ارائه می‌کند.
* ریسک جدی ایمنی یا سلامت محصول وجود دارد.
* شرایط تجاری باعث می‌شود عرضه محصول از نظر اقتصادی ناممکن باشد.

بخش دوم — Product Unit Economics
10. هدف
هدف مدل اقتصاد واحد، محاسبه سودآوری واقعی هر Variant و هر سفارش است.
در فروشگاه خواب‌آور، قیمت خرید پایین لزوماً به معنی سودآوری بالا نیست. هزینه ارسال، حجم کالا، شکستگی یا خرابی، مرجوعی، تخفیف و هزینه جذب مشتری می‌توانند اقتصاد محصول را تغییر دهند.
تمام محاسبات در نسخه اول باید به تفکیک Variant و مدل تأمین انجام شوند.
11. ساختار هزینه محصول
11.1. هزینه خرید
* قیمت خرید از تولیدکننده یا تأمین‌کننده
* هزینه حمل تا انبار
* هزینه بازرسی و کنترل کیفیت
* هزینه بسته‌بندی اولیه
* هزینه‌های قانونی یا گمرکی مرتبط، در صورت وجود
11.2. هزینه پردازش سفارش
* بسته‌بندی سفارش
* نیروی انسانی آماده‌سازی
* انبارداری قابل تخصیص
* هزینه پردازش و مدیریت سفارش
11.3. هزینه فروش
* کارمزد درگاه پرداخت
* تخفیف
* هزینه بازاریابی قابل تخصیص
* هزینه خدمات مشتری
* هزینه مرجوعی و تعویض
11.4. هزینه لجستیک
* هزینه ارسال
* سهم پرداختی خواب‌آور برای ارسال رایگان
* هزینه ارسال مجدد
* هزینه برگشت کالا
* هزینه بسته‌بندی مقاوم برای محصولات حجیم یا شکننده
12. مدل محاسبه Owned Inventory
برای هر واحد محصول:
Landed Cost = Purchase Cost + Inbound Freight + Inspection Cost + Initial Packaging
هزینه متغیر فروش:
Variable Selling Cost = Payment Fee + Fulfillment Cost + Shipping Subsidy + Expected Return Cost + Other Variable Costs
سود مشارکت:
Contribution Margin = Net Revenue - Landed Cost - Variable Selling Cost
در این مدل، قیمت خرید موجودی متعلق به خواب‌آور است و ریسک خواب سرمایه نیز باید در تحلیل جداگانه لحاظ شود.
13. مدل محاسبه Supplier Sourced
در مدل تأمین‌کننده، هزینه تأمین باید شامل قیمت قطعی مورد توافق، هزینه ارسال تأمین‌کننده و سایر هزینه‌های قراردادی باشد.
Supplier Fulfillment Cost = Supplier Purchase Price + Supplier Shipping Charge + Other Contractual Costs
سود مشارکت:
Contribution Margin = Net Revenue - Supplier Fulfillment Cost - Payment Fee - Customer Shipping Subsidy - Return Cost - Other Variable Costs
در صورتی که تأمین‌کننده مستقیماً کالا را ارسال می‌کند، هزینه‌های بسته‌بندی و پردازش باید طبق قرارداد به‌درستی تخصیص داده شوند.
14. مدل سفارش ترکیبی
در سفارش ترکیبی ممکن است کالاهای مختلف از چند انبار یا تأمین‌کننده ارسال شوند.
برای محاسبه سود:
Order Contribution = Σ Item Contribution - Order Level Costs
هزینه‌های مشترک سفارش مانند تخفیف سبد یا ارسال یارانه‌ای باید با یک قاعده مشخص تخصیص داده شوند.
قاعده پیشنهادی تخصیص تخفیف:
Allocated Discount = Order Discount × (Item Gross Value / Total Eligible Item Value)
برای هزینه ارسال مشترک نیز می‌توان از وزن، حجم یا ارزش کالا استفاده کرد؛ روش انتخابی باید در کل سیستم یکسان و قابل ممیزی باشد.
15. محاسبه درآمد خالص
درآمد خالص نباید با مبلغ پرداخت‌شده مشتری اشتباه گرفته شود.
Net Revenue = Item Selling Price - Discount - Refunds - Applicable Indirect Taxes
نحوه محاسبه مالیات و عوارض باید مطابق وضعیت حقوقی و مالیاتی کسب‌وکار و مقررات جاری ایران تنظیم شود. مالیات بر ارزش افزوده در صورت شمول باید جداگانه مدیریت شود.
16. شاخص‌های اصلی
Gross Profit
Gross Profit = Net Revenue - COGS
Gross Margin
Gross Margin % = Gross Profit / Net Revenue × 100
Contribution Margin
Contribution Margin = Net Revenue - All Variable Costs
Contribution Margin Rate
CM % = Contribution Margin / Net Revenue × 100
Break-even Quantity
Break-even Units = Fixed Costs / Contribution Per Unit
این فرمول زمانی قابل استفاده است که سهم مشارکت هر واحد مثبت و هزینه‌های ثابت و متغیر به‌درستی تفکیک شده باشند.
Return Rate
Return Rate = Returned Units / Delivered Units × 100
Inventory Turnover
Inventory Turnover = COGS / Average Inventory Value
Days Inventory Outstanding
DIO = Average Inventory Value / COGS × Number of Days
در مدل Supplier Sourced، شاخص‌های سرمایه درگیر در موجودی باید جداگانه تحلیل شوند.
17. محاسبه هزینه مورد انتظار مرجوعی
هزینه مرجوعی باید با داده واقعی به‌تدریج اصلاح شود.
Expected Return Cost = Return Probability × Average Return Cost
Average Return Cost می‌تواند شامل موارد زیر باشد:
* هزینه ارسال برگشت
* هزینه بررسی و کنترل کیفیت
* هزینه بسته‌بندی مجدد
* افت ارزش کالا
* هزینه ارسال مجدد
* هزینه غیرقابل بازیابی کالا
برای کالاهای بهداشتی یا محصولاتی که پس از بازشدن بسته‌بندی امکان فروش مجدد ندارند، سیاست مرجوعی و هزینه مورد انتظار باید جداگانه تعریف شود.
18. مدل قیمت‌گذاری
قیمت فروش باید از ترکیب هزینه، بازار، ارزش پیشنهادی و محدودیت‌های رقابتی تعیین شود.
فرمول ساده قیمت فروش هدف:
Target Price = Total Unit Cost / (1 - Target Contribution Margin Rate)
این فرمول زمانی مناسب است که هزینه‌های متغیر و ثابت تخصیص‌یافته در Total Unit Cost به‌درستی محاسبه شده باشند و نرخ هدف بین صفر و یک باشد.
قیمت نهایی نباید صرفاً با افزودن درصد ثابتی به قیمت خرید تعیین شود.

	22. قواعد اعتبار داده‌های اقتصادی
* قیمت خرید باید دارای تاریخ و منبع باشد.
* قیمت تأمین‌کننده باید تاریخ اعتبار داشته باشد.
* هزینه ارسال باید بر اساس مقصد، وزن و ابعاد قابل محاسبه باشد.
* هزینه مرجوعی در ابتدا برآوردی است و پس از فروش با داده واقعی جایگزین می‌شود.
* هزینه بازاریابی باید در سطح محصول یا سفارش به‌صورت شفاف تخصیص داده شود.
* قیمت فروش و سود مشارکت باید با تغییر هزینه‌ها مجدداً محاسبه شوند.
* داده‌های قدیمی نباید به‌عنوان قیمت معتبر استفاده شوند.
* تمام مقادیر پولی باید واحد پول مشخص داشته باشند.
واحد اصلی محاسبات مدیریتی در نسخه اول: IRR (ریال).
رابط کاربری می‌تواند برای مشتری قیمت را به تومان نمایش دهد، اما تبدیل ریال و تومان باید در یک لایه واحد و بدون ابهام انجام شود.
23. هشدارهای اقتصادی
محصول در شرایط زیر نباید بدون بازبینی قابل عرضه باشد:
* سود مشارکت صفر یا منفی
* قیمت تأمین نامعتبر یا منقضی
* هزینه ارسال نامعلوم
* نرخ مرجوعی غیرعادی
* موجودی تأمین‌کننده تأییدنشده
* تغییر ناگهانی قیمت خرید
* هزینه تأمین بالاتر از قیمت رقابتی قابل قبول
* عدم امکان اجرای تعهد ارسال
حداقل حاشیه سود قابل قبول هنوز باید با توجه به هزینه‌های ثابت، هزینه جذب مشتری، مالیات و اهداف تجاری خواب‌آور تصویب شود.
